# TaxMate

This is a basic Core PHP project structure.

## Project Structure

- `config/` - application configuration
- `includes/` - reusable layout files
- `assets/css/` - frontend styles
- `index.php` - main entry point

## Run Locally

1. Start Apache in XAMPP.
2. Place this folder inside `xampp/htdocs`.
3. Open `http://localhost/TaxMate/` in your browser.

## Customization

- Update values in `config/app.php`.
- Update database details in `config/database.php`.
- Add your PHP pages and logic inside the project root.
